# Mohsin Adnan Online Store

Android WebView starter project for the UAE store.

## Build APK
A GitHub Actions workflow builds a debug APK when app source changes or when manually started from the Actions tab.

Artifact: `Mohsin-Adnan-Online-Store-debug`.

## Current scope
- Android app shell with local HTML storefront.
- Bangla, English and Arabic interface toggle.
- AED and USD display toggle (fixed illustrative conversion rate; verify current rate before using for real transactions).
- MOHSIN AI is currently a local demo FAQ assistant, not a live AI service.
- Checkout is a demo. No payment gateway, customer database, inventory system or live order backend is connected.
- No payment or withdrawal capability is enabled. Any future money movement must require the owner's explicit approval.

Do not publish this as a live store until products, prices, delivery, privacy terms, backend security and payment provider are configured and tested.
